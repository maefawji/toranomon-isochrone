# 虎ノ門ヒルズ駅 到達圏マップ

虎ノ門ヒルズ駅（日比谷線）から電車と徒歩で 20・30・40 分以内に行ける範囲の地図です。

公開ページ: https://maefawji.github.io/toranomon-isochrone/

- 平日 10:00〜10:57 に3分おきに出発した場合の到着時刻を、実際の時刻表から計算しています。
- 「ふつうに出発」は待ち時間込みの中央値、「うまく乗れたら」は最短値です。
- 駅に着いたあとは、残りの時間で歩ける範囲（分速80m、道のりは直線の1.3倍）を円で描いています。
